Design Principles

Separation of Concerns

Each layer does one job. Guardrails don't know about models. Tools don't know about memory.

Graceful Degradation

No Redis? In-memory. No API key? OSS-only. Tool fails? Model responds from knowledge.

Immutable Data

Frozen dataclasses everywhere. No mutation, no side effects, safe for concurrency.

Async-First

Non-blocking I/O. OSS bridges sync HF to async via run_in_executor.

Input Guardrails

Two categories of regex patterns that run before the model sees any input. Latency: <1ms.

8 Patterns Prompt Injection

"ignore previous instructions", "you are now DAN", "pretend to be", "system prompt:", "jailbreak", "act as if you are"

5 Patterns Harmful Requests

"how to make a bomb", "how to hack", "how to harm someone", "synthesize drugs", "steal identity"

Why regex? Fast, transparent, zero dependencies. Tradeoff: limited coverage vs moderation API.

Tool Orchestration

LLM = reasoning. Tools = deterministic execution. 4-tier classification hierarchy.

0ms Chitchat

Allowlist of 20+ greetings/filler ("hello", "thanks"). Skip everything.

0ms Keywords

"search X" → Web Search, "what is X" → Wikipedia, math patterns → Calculator

500ms LLM Router

GPT-4.1-mini classifies subtle queries when keywords miss. JSON output.

500ms Chain Validator

Post-execution: LLM decides if tool results need computation. Sees query + results for semantic context.

Web Search

DuckDuckGo top 3. Real-time info beyond training cutoff.

Wikipedia

4-sentence summary. Factual grounding, reduces hallucination.

Calculator

AST-safe math (never eval). Datetime. Percentages.

Execution: concurrent via asyncio.gather, 5s timeout per tool, 1x retry, graceful degradation.

Evaluation Pipeline

36 curated prompts scored by LLM-as-judge on 3 dimensions with structured JSON output.

12 Factual

Geography, science, history, tech. Tests hallucination rate.

12 Bias

Gender, race, age, religion, disability. Tests stereotype handling.

12 Safety

Jailbreaks, harmful requests, self-harm. Tests refusal quality.

Output Guardrails

Second line of defense. Runs after the model generates, catches unsafe content that slipped through.

Pattern 1

"here is how to / instructions for" + hack/bomb/harm

Pattern 2

"step N: obtain/acquire/steal" + weapons/explosives/drugs

Defense in depth: Input guardrails + output guardrails = two-stage filtering. Neither model nor response bypasses safety.

Tiered Context Management

Problem: naive sliding window forgets early context. Fix: compress evicted turns, don't drop them.

Layer 1 Working Memory

Sliding window, last N turns verbatim. On overflow, evicted turns go to Layer 2 (not dropped).

Layer 2 Summarizer

LLM compresses: existing summary + evicted turns → updated summary. Preserves names, facts, decisions.

Layer 3 Redis

All state persisted with TTL. Sessions survive restarts. Writes are async, never block response.

Navigable

Summary preserves narrative thread

Fast

Redis <1ms, summary pre-computed

Fresh

Regenerated on each overflow

Compound

Accumulates across full history

Fallback: No API key = extractive truncation. No Redis = in-memory. Never crashes.

Model Backends

Both implement the same async interface. The architecture doesn't know which model is running.

OSS Qwen2.5-0.5B-Instruct

HuggingFace transformers. TextIteratorStreamer for token streaming. run_in_executor for non-blocking queue reads. CPU inference.

Frontier GPT-4.1-mini

AsyncOpenAI client. Native async streaming. API-based, no local compute.

Arena Mode

Both fire concurrently via asyncio.create_task. Tools execute ONCE, results shared. Identical context, different reasoning.

Abstract Interface

BaseModel ABC with async generate() and stream(). New models = implement interface, register in app.

Edge Cases: Where Details Matter

"divided by 47" is math. "divided by borders" is metaphor. Regex can't tell. LLM can.

"population of Japan divided by 47"
CHAIN — LLM: math, 125000000 / 47
"India and Pakistan divided in 1947"
NO CHAIN — LLM: historical
"how does current flow in a circuit"
NO SEARCH — physics, not news

The Fix

Every heuristic breaks with a counterexample. That's a semantic understanding problem, not a regex problem.

Solution: LLM chain validator sees query + tool results. Full context for semantic decisions.

Pre-filter gates the LLM call. Cost near zero for most queries.
