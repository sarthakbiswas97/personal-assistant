Design Principles

Separation of Concerns

Each layer does one job. Guardrails don't know about models. Tools don't know about memory.

Graceful Degradation

No Redis? In-memory. No API key? OSS-only. Tool fails? Model responds from knowledge.

Immutable Data

Frozen dataclasses everywhere. No mutation, no side effects, safe for concurrency.

Async-First

Non-blocking I/O. OSS bridges sync HF to async via run_in_executor.

Edge Cases: Where Details Matter

"divided by 47" is math. "divided by borders" is metaphor. Regex can't tell. LLM can.

"population of Japan divided by 47"
CHAIN — LLM: math, 125000000 / 47
"India and Pakistan divided in 1947"
NO CHAIN — LLM: historical
"how does current flow in a circuit"
NO SEARCH — physics, not news

The Fix

Every heuristic breaks with a counterexample. That's a semantic understanding problem, not a regex problem.

Solution: LLM chain validator sees query + tool results. Full context for semantic decisions.

Pre-filter gates the LLM call. Cost near zero for most queries.
